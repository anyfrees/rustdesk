# 官方手机客户端公钥兼容

当前 Windows UI9 将服务器签名公钥独立内置，手机官方客户端没有这个改动。手机旧配置的短 Key 是历史访问口令，不是 32 字节 Ed25519 公钥，因此不能验证服务器签名。

新增 public-key-alias.patch 在 hbbs 和 hbbr 的原鉴权条件旁增加可选公钥别名检查。NNU_PUBLIC_KEY_ALIAS 必须为非空、Base64 可解码为 32 字节的公钥，且客户端提交值必须精确匹配；原口令和空口令模式行为保留，不配置环境变量时行为不变。沿用相同签名私钥、ID 数据、端口和命令。没有隐藏客户端安全提示。
