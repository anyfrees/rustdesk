# RustDesk NNU 1.5.0 Windows x64

基于 RustDesk 官方 1.5.0 稳定版。适用于你有权管理、且使用者知情的设备。

## 文件选择

- `RustDesk-NNU-1.5.0-x64-Portable.exe`：单文件便携版，双击运行，把界面上的 ID 发给 IT。
- `RustDesk-NNU-1.5.0-x64-Install.exe`：EXE 安装入口，由用户选择安装。
- `RustDesk-NNU-1.5.0-x64.msi`：标准 Windows Installer 安装包。
- `RustDesk-NNU-1.5.0-x64.zip`：完整文件夹版，解压后运行 `rustdesk.exe`。

## 便携版密码

便携版在没有安装 RustDesk、没有现有永久密码，且没有初始化记录的设备上，首次正常启动会写入管理员指定的固定密码。
固定密码通过本机构建环境变量 `NNU_PORTABLE_PASSWORD` 编译注入，不写入公开源码。
密码通过 RustDesk 原生加盐哈希存储，并保留连接管理窗口和托盘提示。
用户可在“设置 → 安全”中修改或清除密码；以后启动不会恢复管理员初始密码。
已安装 RustDesk 的电脑沿用原有认证设置。安装版不为全机服务自动设置共享固定密码。
密码模式下，知道该密码的 IT 在获得 ID 后可以连接，无需同事再次点击接受。
退出托盘中的 RustDesk 可结束便携版支持。

## 更新与验证

UI12 新增连接窗口显示选项、安装版管理 PIN 和可选意外恢复；UI13 统一列表样式、沿用设置 PIN，并修复仅密码模式的隐藏开关，详见 [管理与连接窗口设置](NNU-Teaching-Protection.md)。管理保护与意外恢复默认关闭；正常自动升级无需管理 PIN。

默认关闭上游自动更新与更新检查，避免 DIY 包被官方客户端替换；UI4 起可使用底部“检查更新”从自建服务获取定制版。后续发布仍需从此定制分支构建并签名。

UI20 起，启用 NNU 自动更新的 Windows 安装版手动检查也交由原生更新器处理，验证后静默安装，无需重复打开安装向导。原生更新器等待远程会话结束，后台自动检查还等待本机空闲；系统提权提示仍需用户确认。关闭自动更新或使用便携版时保留手动下载流程。多平台后台及 Android/Linux 在线检查、下载说明见 `NNU-Multiplatform.md`。
UI9 起默认开启自建服务自动更新（UI10 起选项移至常规列表），可在“设置 → 常规 → 其他”中取消“自动下载并安装更新”。客户端启动后自动检查，之后每 6 小时检查；忙碌或失败时稍后重试。只有发现更高内部版本号、Ed25519 签名和下载文件 SHA256/大小全部正确，且没有远控会话、电脑空闲至少 5 分钟时才安装。安装前再次检查会话与空闲状态。
MSI、安装 EXE 沿用原生安装流程；普通权限的便携 EXE、ZIP 会更新原程序并重新启动，保留原 ID、密码和设置。管理员身份运行的便携版须手动更新。安装权限及 Windows 安全确认由系统控制。便携更新失败记录位于 `%LOCALAPPDATA%\NNU\ClientUpdates\update.log`。
旧版本需要先手动升级一次才能获得自动更新功能。发布助手会为每次构建生成并签名四类安装包和升级发布包，并同步写入客户端版本元数据；发布该升级包后，新版客户端即可自动获取后续定制版本。仅构建不会自动向所有设备推送。
连接安全修复保留旧访问口令和中继配置，需要配套启用服务端身份签名，见 `res/nnu/server-compat/README.md`。旧版客户端可继续连接，其自身的安全提示需升级客户端后才能改善。
本包未配置商业代码签名证书。请通过附带的 SHA256SUMS.txt 核对下载文件。
安装版需要管理员权限；便携版控制 UAC / 管理员窗口时可能需要用户主动提权。

可复现源码：anyfrees/rustdesk 的 `nnu/windows-1.5.0` 分支，以及 anyfrees/hbb_common 同名分支。
当前采用本机编译，不再消耗 GitHub Actions 额度。保留的工作流仅供今后自行启用。
本机构建使用 Rust 1.75.0、Flutter 3.24.5、LLVM 15.0.6 和 Visual Studio 2022 Build Tools。
Flutter 构建目录应使用英文路径；本机准备好的目录位于 `%USERPROFILE%\.codex\tools\nnu-build\source`。

## 自定义连接 ID（UI10）

在“设置 → 安全 → ID → 更改 ID”填写新编号；如页面已锁定，先解锁。采用 6–16 个字符，以英文字母开头，后续可用英文字母、数字、下划线或连字符，例如 `nnu-office-01`。服务端检查设备签名、名称占用及历史归属；每台设备成功修改后至少等待 2 分钟才能再次修改。已有设备不会自动改号。配套 API 扩展会同步设备和地址簿中的编号，保留账号归属、分组及保存的信息；API 暂时离线时自动重试，历史日志保留原编号。修改 ID 不会重设密码或设备密钥。需要配套启用自定义 ID 和 API 同步的服务端。
