# 管理与连接窗口设置（UI14）

本功能从 UI12 提供。管理保护与意外恢复默认关闭，由设备管理员自行开启。

## 设置入口

Windows 安装版：设置 → 安全 → 管理。先按原有流程解锁安全设置。

- **退出和卸载时验证 PIN**：默认关闭。先在上方“使用 PIN 码解锁设置”中设置 PIN，再开启保护；开启时请求 Windows 管理员授权，不再设置第二个 PIN。它不替代远控密码或账号密码。
- 正常退出、停止服务、EXE 卸载和本版本 MSI 的独立卸载会验证管理 PIN；取消或校验失败不会执行这些操作。关闭主窗口收回托盘不等于停止远控服务，不弹 PIN。
- 修改上方设置 PIN 后，由已安装服务同步保护校验；保护开启时不能直接清空设置 PIN，须先关闭保护。关闭保护和修改恢复设置仍需要 Windows 管理员授权及 PIN 验证。UI12 已启用独立 PIN 的设备在服务升级启动后，若已设置解锁 PIN，会迁移为共用该设置 PIN。
- PIN 以随机盐和 600,000 次 PBKDF2-HMAC-SHA256 的校验值保存到 HKLM 的 64 位注册表视图，普通账户不能写入。输入不通过命令行传递，不记录到日志，也不保存到 Windows 凭据管理器。
- 验证界面复用客户端现有的圆角对话框、密码输入和按钮主题，只显示 PIN，不使用 Windows 的通用用户名/密码凭据框。取消、关闭、界面启动失败或校验失败均不授权；PIN 在本机原生层验证。
- UI14 的 PIN 专用窗口使用透明背景和无系统边框，只保留圆角卡片，标题区域可拖动；旧 Windows 兼容模式保留标准窗口。此修改不改变主窗口、会话窗口或 PIN 校验规则。
- 保护面向安装版。限制资源管理器直接删除文件需要使用受权限保护的安装目录及非管理员学生账户；应用 PIN 不会把用户进程变成 Windows 受保护进程。管理员仍可执行系统维护；普通用户也可能同时终止界面和恢复监视进程，后台系统服务的权限由 Windows 控制。

## 自动升级

自建自动更新原有的版本、签名、SHA256、大小、空闲及会话检查保持有效。手动 EXE 覆盖安装和 EXE 自动更新均不调用手动卸载 PIN 校验；EXE 卸载校验只在明确的卸载入口执行，不放入安装复用的清理脚本生成函数。MSI 的 MajorUpgrade 删除旧包通过 `UPGRADINGPRODUCTCODE` 排除独立卸载校验。保护与恢复偏好保存在安装目录外，升级后保留。

UI14 从启动约 30 秒开始检查，正常每 5 分钟检查，因会话/本机操作延后或网络失败时每分钟重试，取代原有 6 小时正常检查和 30 分钟重试。只在无远控会话且连续空闲 5 分钟时自动安装，下载完仍重新检查这些条件；测试机一直处于远控连接中时会延后。

用户主动停止服务、关闭程序后，下一次主动打开 NNU 主客户端，会恢复原有启动服务流程，必要时请求 Windows 管理员授权；便携版恢复连接服务开关。不在关闭期间拉起服务，不对安装工具、托盘、PIN 窗口、`--no-server` 或崩溃恢复命令执行该恢复；仅控制端配置保持原行为。取消系统授权或原启动流程失败时保留停止状态。

恢复开启时，安装/更新函数持有进程寿命内的命名更新锁，界面监视进程发现更新锁或后台服务已停止时不重启界面。更新锁申请失败只记录告警，不以此阻止更新。安装程序会结束旧客户端进程，后续启动的新客户端重新建立监视。Windows 的安装权限确认仍由系统控制。

独立静默卸载在保护开启时拒绝执行，不用静默参数绕过 PIN；静默正常升级走上述升级条件。尚未在安装后的隔离 Windows 环境中完成升级、卸载和故障恢复的联合验收，不能将源码检查等同于实机通过。

## 意外退出后自动恢复

默认关闭，可独立选择。后台服务设置立即生效；界面恢复从下次启动客户端生效。

- Windows 服务异常终止后由服务管理器依次在 5、15、60 秒后尝试恢复，连续失败后停止自动重启，计数 1 小时后重置。正常停止服务不触发恢复。
- 界面启动时建立同一安装程序的监视进程，仅在非零异常退出、恢复选项仍开启、后台服务仍运行且无更新锁时，等待 5 秒后重启；连续最多 3 次。正常退出不恢复。
- 不接管会话窗口、安装工具或其他程序的进程，也不自动恢复远控会话。机器关机、用户注销和系统管理员维护不作为必须阻止的操作。

## 管理员恢复

忘记管理 PIN 时，系统管理员可以运行**安装目录中的** `RustDesk.exe --nnu-teaching-recover`，通过 Windows 管理员授权并确认后关闭保护。普通学生账户不能自行完成该恢复。恢复不改远控密码、ID 或账号。

## 连接管理窗口

桌面端：设置 → 安全 → 管理 → 连接时显示连接管理窗口，默认显示。该选项始终列出，不再藏在固定密码选项内。

连接批准方式为“仅密码”时允许关闭自动弹出，支持临时密码、固定密码或两者；仍需人工点击同意的连接继续显示窗口。切换到需要人工确认的批准方式会清除隐藏选项。设置通过现有 IPC 和状态刷新同步到连接管理进程，重新开启后可恢复显示；托盘与连接状态保留。

## 本次影响的既有运行路径

| 文件 | 必要改动 |
|---|---|
| `src/platform/windows.rs` | EXE 卸载及停止服务增加校验；安装/更新暂停恢复；服务启动恢复系统策略；管理员设置入口。 |
| `src/core_main.rs` | 分派管理/恢复/卸载校验命令；仅主动打开主客户端时恢复已停止的服务；按用户选择建立界面监视，恢复启动不重复建立监视。 |
| `src/updater.rs` | 只缩短 NNU Windows 自建服务的自动检查与重试间隔，保留其它更新通道原有调度。 |
| `flutter/lib/main.dart`、`flutter/windows/runner/main.cpp` | 只为 PIN 验证启动独立轻量窗口，不启动主客户端、托盘或远控服务。 |
| `src/flutter_ffi.rs` | 通过已有 common 接口传递管理操作及查询状态，不改生成的桥接协议。 |
| `src/ui_interface.rs` | 防止未安装路径直接设置停止服务绕开校验。 |
| `res/msi/CustomActions/CustomActions.cpp`、`.def` | 独立卸载前同步执行本机校验，失败则取消，保护校验在删除动作前完成。 |
| `res/msi/Package/Components/RustDesk.wxs` | 排列卸载校验并排除升级删除旧包。 |
| `flutter/lib/desktop/pages/desktop_home_page.dart` | 仅接入受控端明确的“退出”按钮。 |
| `flutter/lib/desktop/pages/desktop_setting_page.dart` | 增加管理入口，并启用受密码条件约束的连接窗口选项。 |
| `flutter/lib/models/server_model.dart` | 同步连接窗口偏好并在验证条件变化时恢复显示。 |
| `src/nnu_update.rs` | 定义 NNU 更新检查与重试周期；后台更新读取第二版清单并验证受根密钥授权的外链签名；保留大小、SHA256 和安装前校验。 |
| `src/ipc.rs` | 定制桌面客户端可读取现有 `hide_cm` 结果，只允许在“仅密码”批准模式隐藏窗口，并在设置 PIN 变更时同步 Windows 保护校验。 |
| `res/nnu/release-assistant/engine.py` | 后续构建纳入新增设置控件的回归测试。 |

PIN 与崩溃恢复的主要逻辑位于新增的 `src/platform/windows/nnu_management.rs` 和 `nnu_recovery.rs`；主动打开时恢复停止状态的逻辑位于 `nnu_startup.rs`，复用原有启动服务入口。UI 位于新增的管理及连接窗口组件。管理保护与崩溃恢复默认关闭，关闭时保留原有退出行为；NNU 自动更新及主动打开时恢复服务的行为按上述规则执行。
